Personal Computer Help

Patient, one-to-one help with computer apps, email, files and online accounts.

Ask about this service↗

Get clear help with the technology you use.

You don’t need to know the technical name for a problem. Describe what you are trying to do and what happens instead. Ryan can help with suitable computer and software tasks through a scheduled remote appointment.

Does this sound familiar?

  • I need help setting up email or using an application.
  • I have a new computer and need my files and software organised.
  • I want help with backups, safer sign-in or understanding a technology task.

Who this is for: Individuals who want practical, understandable help with a computer, software or an online account.

A useful first step

Tell us which device you use and what you need help with. We’ll check whether a remote appointment is appropriate and agree the cost first.

Tell Ryan what you need↗

What this can include

The exact work is agreed around the task you need help with.

Computer and application help

Work through suitable Windows, software installation and everyday application problems.

Email and file setup

Help organise email, files and cloud storage, or plan a transfer between working devices.

Backup and sign-in help

Help configure an agreed backup, stronger passwords and multi-factor sign-in on your own accounts.

One-to-one guidance

Explain an agreed task step by step, with notes you can use after the appointment.

Example of a starting project

Getting comfortable with a new computer

Set up the agreed applications and email, organise important files, and walk through a backup and the everyday tasks you want to learn.

Scope, costs and next steps

Remote help is best suited to working devices that can connect to the internet. The task and any access are agreed with you before the appointment.
